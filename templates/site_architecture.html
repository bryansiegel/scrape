2. Link Reorganization

Upload a list of links as a .txt file (one URL per line). Each page is scraped for its plain text content (no HTML/CSS) and categorized by Ollama into a folder structure modeled after how large district sites (e.g. cps.edu) are organized. Only the folder changes — each page's own URL slug is preserved exactly. If you've loaded a phone directory above, those official department names are used as the vocabulary for /about/departments/ pages.
